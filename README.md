# RPA_Attendance

RPA_Attendance is a Python-based tool designed to automate the process of capturing, validating, and recording attendance data. It simplifies attendance tracking by extracting data from Excel or CSV files, validating it, and updating records efficiently with minimal manual input.

## Features

- 📄 **Automated Data Extraction**: Pulls attendance data from Excel or CSV files.
- ✅ **Data Validation**: Ensures attendance entries are accurate and formatted correctly.
- 💾 **Efficient Data Recording**: Updates final attendance records with minimal human effort.
- ⚙️ **Customizable Workflow**: Easily configurable for different formats or institutional needs.

## Technologies Used

- **Python**: Core language used for automation.
- **Pandas**: For reading, analyzing, and cleaning attendance data.
- **OpenPyXL**: For handling Excel (.xlsx) file operations.
- **CSV**: Built-in support for handling comma-separated data files.

## Benefits

- ⏱️ **Time-Saving**: Automates repetitive attendance tasks.
- 🧮 **Accurate**: Reduces manual errors in data entry.
- 📈 **Scalable**: Can handle large datasets across multiple files.
- 🛠️ **Flexible**: Easily adapted to new rules or formats.

## Getting Started

1. **Clone the repository**:

    ```bash
    git clone https://github.com/Snowballx7370/RPA_Attendance.git
    ```

2. **Navigate to the project folder**:

    ```bash
    cd RPA_Attendance
    ```

3. **Install required Python packages**:

    ```bash
    pip install -r requirements.txt
    ```

4. **Configure your input/output files** (as needed in the script).

5. **Run the automation script**:

    ```bash
    python automate_attendance.py
    ```
